# Build on it: three feature requests

You are working in a checkout of Twenty v2.58.0 (an open-source CRM; Nx monorepo, React web app in
`packages/twenty-front`, shared UI in `packages/twenty-ui`). Implement the three requests below in
this checkout, as a careful contributor to this project would: the change should look and behave
like it belongs in Twenty. Change only the web app (`twenty-front`, `twenty-ui`, `twenty-shared`);
the server stays as it is. Edit the code directly. You cannot build or run the project here unless
your instructions say otherwise.

1. **Export to CSV.** "On the People list I often need a spreadsheet of a few people. Let me select
   some people and download them as a CSV file."

2. **Copy an address.** "Emails, phone numbers and links have a small copy button when I hover
   them. Give addresses the same one-click copy, on the companies list and on a company's page."

3. **Show how many records there are.** "When I'm on a list like People or Companies, I want to
   see how many records it has, near the page title."

When you are done, reply with: for each request, one or two sentences on what you changed (file
names), and anything you decided not to change and why.
