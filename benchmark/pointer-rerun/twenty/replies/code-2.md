All three requests are handled, but two of them differed from what the request assumed. Nothing was built, linted, typechecked or tested, and I didn't add tests.

1. **Export to CSV: no change.** Selecting rows and running "Export People" already downloads only those rows. The command is `EXPORT_RECORDS` in `packages/twenty-front/src/modules/command-menu-item/engine-command/record/components/ExportRecordsCommand.tsx`, and it filters on the selected IDs via `computeContextStoreFilters.ts`. It appears in the selection actions menu (`RecordIndexCommandMenuDropdown.tsx`) and needs the `EXPORT_CSV` permission. It isn't pinned to the selection bar, and that setting lives in the server seed (`standard-command-menu-item.constant.ts`), which is out of scope here.

2. **Copy an address: changed `packages/twenty-front/src/modules/object-record/record-field/ui/meta-types/display/components/AddressFieldDisplay.tsx`.** Emails, phones and links don't have a hover copy button in this checkout. They only copy on click, and only when the field's click action is set to copy. So there was no existing control to match. I added a copy button that appears on hover or focus, reusing `LightCopyIconButton`. The wrapper stops clicks from bubbling so copying doesn't open cell edit mode. This one component serves both the companies list and the company page. The toast reads "Text copied to clipboard" because the shared button takes no custom message. I did not add hover copy to emails, phones or links, since that wasn't asked and would be a new pattern; say if you want it.

3. **Record count: changed `packages/twenty-front/src/modules/object-record/record-index/components/RecordIndexPageHeaderTitle.tsx` and `RecordIndexPageHeader.tsx`.** The count now appears in tertiary text after the page title, using the existing `useGetRecordIndexTotalCount` hook, so it respects the view's filters. The new `totalCount` prop is optional, so the AI inbox heading and core object layout are unaffected. The count is hidden until it loads rather than showing 0.
