# Answer key

Written before any test run, from the running app (Memos v26.11.0, demo mode, 1440x900, new
member account). One point per question. A point needs every required element; extra correct
detail is fine; a wrong element (a wrong item, a wrong order, a wrong on/off state) loses the point.

1. "Welcome back."
2. A language selector showing "English" and a theme selector showing "System". Both required.
3. "Don't have an account yet?" followed by a "Sign up" link.
4. Group heading "Basic" (shown in capitals), then exactly: My Account, Spaces, Access Tokens, Preferences, Editor, Webhooks, Tags, Export & Import. Order and completeness required; no admin sections.
5. Appearance, Memo defaults, Uploads & privacy, This device. Order required.
6. Save media metadata: off. Link preview: on. Double-click to edit: off. All three required.
7. Theme: "Sync with system". Default memo visibility: "Private". Both required.
8. "Any thoughts..."
9. A "+" (add/insert) button, then a visibility selector showing "Private" (lock icon), then a "Save" button at the right end. All three in that order; Save appears dimmed/disabled.
10. In order: the user's avatar and name with a switcher, plus a new-memo button; the navigation row (Timeline, calendar, map, attachments, search); a month calendar; "Views" with "Create view"; "Tags" with the tag list. The point needs calendar, views and tags in that order below the navigation; the header detail is optional.
11. Only "Timeline" shows a text label (with a dropdown arrow). Calendar, Map, Attachments and Search are icon-only.
12. "Memos demo" followed by "Feel free to explore! This demo is reset periodically." and a "Deploy your own Memos" link, in a bar across the top of the main content area (to the right of the sidebar). Text and top position required.
13. Filters: All, Unread, Archived. Empty state: "No data found." Both required.
14. "No data found."
15. "The page you are looking for can't be found." and "404". The sentence is required.
16. Official Website, Documents, API Docs, GitHub Repo, Web Clipper, Sponsor Memos. Order and completeness required.
17. Account Information (username with Edit and Change password), Statistics / Attachment storage, Usage limits, SSO Accounts, Danger area (Delete account). The point needs account information, usage limits, SSO accounts and danger area in that order; statistics optional.
18. Top-left: a relative time ("1 minute ago"). Top-right: a three-dot (more) menu button.
19. As a small rounded pill/chip containing "#books" (tinted, with a border), inline in the text.
20. A "#" icon, the tag name, and the number of memos with that tag at the right.
