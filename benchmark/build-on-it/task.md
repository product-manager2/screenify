# Build on it: three feature requests

You are working in a checkout of Memos v26.11.0 (an open-source notes app; Go backend, React web
client in `web/`). Implement the three requests below in this checkout, as a careful contributor
to this project would: the change should look and behave like it belongs in Memos. Edit the code
directly. You cannot build or run the project here unless your instructions say otherwise.

1. **Copy a memo's text.** "I often want to paste a memo's text somewhere else. Let me copy a
   memo's text to the clipboard straight from the memo card in the timeline."

2. **Duplicate a memo.** "Add a 'Duplicate' action to a memo's ⋮ menu. It creates a new memo with
   the same content and visibility, and tells me it worked."

3. **Show when a memo was edited.** "Show a small 'edited' label on memos that were changed after
   they were created, so readers can tell."

When you are done, reply with: for each request, one or two sentences on what you changed (file
names), and anything you decided not to change and why.
